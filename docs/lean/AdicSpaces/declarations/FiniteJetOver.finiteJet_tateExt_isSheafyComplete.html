FiniteJetOver.finiteJet_tateExt_isSheafyComplete

Mathematical summary.

Let K be a complete nontrivially normed ultrametric field with a chosen uniformizer and noetherian norm unit ball. For every n≥0, the finite Tate extension 𝓐⟨V₁,…,Vₙ⟩ of the finite-jet algebra 𝓐=JetA K, with its canonical Tate-algebra topology, is sheafy for every ring of integral elements. Lean extends the Milnor square coefficientwise, proves that the other three vertices remain strongly noetherian, applies Milnor-square descent, and transports the result to the canonical topology.

theorem finiteJet_tateExt_isSheafyComplete (ϖ : Uniformizer K)
    (hK₀ : IsNoetherianRing (FiniteJet.unitBall K)) (n : ℕ) :
    letI := mvTateAlgebraTopology' (A := JetA K) n
    haveI := mvTate_isTateRing (A := JetA K) n
    haveI := mvTate_t2Space (A := JetA K) n
    haveI := mvTate_nonarchimedean (A := JetA K) n
    haveI := mvTateAlgebraTopology'_isTopologicalRing (A := JetA K) n
    haveI : @CompleteSpace ↥(restrictedMvPowerSeriesSubring n (JetA K))
      (IsTopologicalAddGroup.rightUniformSpace _) := finiteJet_tateExt_completeSpace K n
    IsSheafyComplete ↥(restrictedMvPowerSeriesSubring n (JetA K))
