Restricted-series infrastructure. The weighted-parity development uses restricted power-series code adapted from William Coram's repository, whose univariate Gauss-norm layer builds on Fabrizio Barroero's mathlib code. It separately uses Bingyu Xia's multivariable power-series equivalences. This is infrastructure provenance, not an attribution of this paper-specific declaration.
