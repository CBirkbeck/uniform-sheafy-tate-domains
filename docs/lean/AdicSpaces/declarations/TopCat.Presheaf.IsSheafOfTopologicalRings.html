TopCat.Presheaf.IsSheafOfTopologicalRings

Mathematical summary.

For a bundled presheaf F of complete separated topological commutative rings, F.IsSheafOfTopologicalRings requires that, for every topological commutative ring T, compatible families of continuous homomorphisms T → F(Uᵢ) glue uniquely over every open cover. This is the generic bundled form of Wedhorn’s representable sheaf condition.

The mathematical summary is editorial text for this paper. The declaration below is extracted verbatim from the pinned source.

Original Lean docstring

Wedhorn Remark 8.20 for an arbitrary bundled presheaf: for every
topological commutative test ring T (in the working universe — no completeness,
separation, or discreteness assumed) and every open cover, compatible families of
continuous ring homomorphisms into the members glue uniquely.

Used in the paper for: Appendix A (Wedhorn's representable predicate); Appendix: generic bundled form of Wedhorn's sheaf condition

def IsSheafOfTopologicalRings : Prop :=
  ∀ (T : Type u) (_ : CommRing T) (_ : TopologicalSpace T) (_ : IsTopologicalRing T),
    ∀ {ι : Type u} (U : ι → Opens X)
      (f : ∀ i, {g : T →+* (F.obj (op (U i)) : Type u) // Continuous g}),
      (∀ i j : ι,
        (F.map (homOfLE (inf_le_left (a := U i) (b := U j))).op).1.comp (f i).1 =
        (F.map (homOfLE (inf_le_right (a := U i) (b := U j))).op).1.comp (f j).1) →
