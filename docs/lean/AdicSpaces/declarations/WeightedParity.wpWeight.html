WeightedParity.wpWeight

Mathematical summary.

For a finitely supported exponent vector ν, wpWeight w ν is the sum of w(n) over the nonzero indices at which νₙ is odd. Index zero is reserved for the variable W and does not contribute.

The mathematical summary is editorial text for this paper. The declaration below is extracted verbatim from the pinned source.

Original Lean docstring

The parity weight ω(ν) = ∑_{n ≥ 1, ν_n odd} w n of an exponent t : ℕ →₀ ℕ
([WP] eq:parity-weight, with the generalized weight w; the paper's example is
w = id). Index 0 (the W-variable) never contributes.

Used in the paper for: Appendix: weighted-parity weight

def wpWeight (w : ℕ → ℕ) (t : ℕ →₀ ℕ) : ℕ :=
  ∑ n ∈ t.support, if t n % 2 = 1 ∧ n ≠ 0 then w n else 0
