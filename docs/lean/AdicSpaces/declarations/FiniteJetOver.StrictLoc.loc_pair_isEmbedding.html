FiniteJetOver.StrictLoc.loc_pair_isEmbedding

Mathematical summary.

For every rational datum, the canonical map A_α → B_α ×_{D_α} C_α is a topological embedding. Lean proves a quotient-norm estimate ‖x‖≤C max(‖x_B‖,‖x_C‖) by correcting nearly minimal representatives; this makes the map antilipschitz. Together with algebraic exactness, it identifies A_α with the topological fibre product.
