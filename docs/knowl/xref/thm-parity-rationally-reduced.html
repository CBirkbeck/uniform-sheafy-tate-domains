Theorem 7.13.

Every finite iterated rational localization of \(\mathcal A\) is reduced.
🔗
🔗

Proof.
By transitivity of rational localization, it is enough to treat one rational localization. Use Corollary 7.10 to write it as
\begin{equation} E\cong\widehat{\bigoplus}_{\mu}^{c_0}Pe_\mu, \qquad P=(\mathcal A_N)_\alpha.\tag{7.35} \end{equation}
The affinoid algebra \(\mathcal A_N\) is a domain by Lemma 7.3. A rational localization of a reduced affinoid algebra is reduced [bib-BGR, Corollary 7.3.2/10]; see also [bib-KedlayaAWS, Remark 1.2.16]. Thus \(P\) is reduced.
🔗
The element \(W\) is a non-zero-divisor in \(\mathcal A_N\text{.}\) Affinoid rational localization is algebraically flat [bib-BGR, Corollary 7.3.2/6]; see also [bib-ConradL15, Proposition 15.1.1, proof]. Tensoring \(0\to\mathcal A_N\xrightarrow{W}\mathcal A_N\) with \(P\) therefore shows that multiplication by \(W\) is injective on \(P\text{.}\) If \(P=0\text{,}\) the conclusion is immediate, so assume otherwise.
🔗
Let \(J=\{n>N\}\text{.}\) Define
\begin{equation} \Phi:E\longrightarrow\mathcal F_J(P), \qquad \Phi\left(\sum_\mu x_\mu e_\mu\right) =\sum_\mu W^{\omega(\mu)}x_\mu U^\mu.\tag{7.36} \end{equation}
The multiplication rule (7.23) makes \(\Phi\) multiplicative. If \(\Phi(\sum x_\mu e_\mu)=0\text{,}\) coefficient comparison gives \(W^{\omega(\mu)}x_\mu=0\) for every \(\mu\text{.}\) The \(W\)-regularity of \(P\) then gives \(x_\mu=0\) for every \(\mu\text{,}\) so \(\Phi\) is injective. By Lemma 7.12, the target is reduced; hence \(E\) is reduced.
