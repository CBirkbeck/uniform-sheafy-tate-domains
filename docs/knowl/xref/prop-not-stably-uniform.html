Proposition 4.2.

The ring \(A\) is not stably uniform.

Proof.
In \(T=k\langle X,Q\rangle/(Q^2)\text{,}\) every element of the line \(kQ\) is nilpotent and hence power-bounded. This line is not bounded with respect to the ring of definition \(T_0\text{:}\) for every \(r\geq 0\text{,}\)
\begin{equation*} \varpi^r\bigl(\varpi^{-(r+1)}Q\bigr)=\varpi^{-1}Q\notin T_0. \end{equation*}
Thus \(T\) is not uniform. By Proposition 4.1, \(A_\alpha\) is not uniform.
